# Reporting a security issue

Use **Report a vulnerability** on the repository's Security tab when private vulnerability reporting is available. If the button is unavailable, contact a maintainer privately to arrange a reporting channel before sending details. Keep vulnerability details out of public issues and pull requests while a fix is being prepared.

Include the affected revision, operating system, expected and observed behavior, and the smallest safe reproduction. Replace tokens, private source, and workspace data with synthetic values.

LocalCoder binds its API to loopback by default. The coding agent runs configured repository commands with the current user's permissions. Use the agent only in a workspace whose code and scripts you trust.
